# WaziBot AI Development Workspace

This folder is for plans and review records produced by the Claude Code lead agent.

- `architecture-review.md`: verified repository architecture and important dependencies.
- `implementation-plan.md`: task scope, affected files, sequence, approvals, risks, and rollback.
- `change-log.md`: concise record of approved changes and test results.

Do not place secrets, access tokens, personal customer data, production exports, or unredacted logs here.
- `ARCHITECTURE_MAP.md`: module map, request flow, AI priority order, data model notes, test conventions and known limits.
- `OPERATIONS_RUNBOOK.md`: scheduled jobs and their once-only guards, migrations and their effects, environment variable names, safe switches, post-deploy checks, rollback.
- `PHASE_*_REPORT.md`, `PHASE_7_PLAN.md`: per-phase evidence and decisions; `SCALING_NOTES.md`: what must change before running more than one worker.
